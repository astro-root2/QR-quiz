# QRコード早押しクイズシステム

## セットアップ

1. `.env.example` を `.env.local` にコピーし、Supabaseプロジェクトの値を設定する
2. `supabase/migrations/0001_init.sql` をSupabaseプロジェクトのSQL Editorで実行する
3. `npm run dev` で起動する

## 実装ステップ

- Step1: プロジェクト初期構築（完了）
- Step2: 認証
- Step3: DB接続確認
- Step4: API実装
- Step5: プレイヤー画面
- Step6: ボタン処理（同時押し制御）
- Step7: 管理画面
- Step8: QRコード生成
- Step9: 得点管理
- Step10: テスト
- Step11: デプロイ
